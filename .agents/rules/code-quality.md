# Контроль качества и стандарты разработки

Данный документ определяет критерии надёжности, правила тестирования и валидации кода в проекте «Реквием: Последний выстрел».

---

## 1. Стек технологий и зависимости

- **Технологический стек:** React 18, TypeScript, Tailwind CSS, Framer Motion, PartyKit WebSocket, Vite, Vitest.
- **Минимализм зависимостей:** Запрещено самовольно устанавливать новые `npm`-пакеты. Все задачи должны решаться в рамках существующего стека. Если новая библиотека критически необходима, агент обязан запросить разрешение владельца, обосновав выбор.
- **Строгая типизация TypeScript:** Не использовать тип `any` без крайней необходимости. Все интерфейсы игрового состояния, экшенов и сетевых пакетов типизируются в `src/types/`.

---

## 2. Реальные команды проверки из `package.json`

Для верификации изменений использовать только команды, фактически объявленные в `package.json`:

1. **Автоматические тесты (Vitest):**
   ```bash
   npm test
   # эквивалент: npx vitest run
   ```
   *Запуск конкретного файла теста:*
   ```bash
   npx vitest run src/components/tv/__tests__/TvBoardView.test.tsx
   ```

2. **Проверка типов TypeScript:**
   ```bash
   npx tsc --noEmit
   ```

3. **Сборка production bundle и генерация PWA:**
   ```bash
   npm run build
   # выполняет: tsc && vite build
   ```

4. **Полный аудит проекта (комплексная проверка):**
   ```bash
   npm run audit:all
   # выполняет цепочку: vitest run && tsc --noEmit && vite build
   ```

5. **Оптимизация изображений для прекэша PWA:**
   ```bash
   npm run optimize:assets
   # выполняет: node scripts/optimize-images.mjs
   ```

---

## 3. Инвариант Zero Regression

- **Сохранность существующих тестов:** Ни одна доработка не считается завершённой, если хотя бы один из 41 тестового файла (233+ тестов) падает или пропущен (`skip`).
- **Честность результатов:** Запрещено утверждать, что «всё работает», если проверки фактически не запускались в терминале.
- **Разделение проверенного и непроверенного:** В итоговом отчёте агент обязан чётко разделять:
  - То, что подтверждено зелёными тестами и сборкой.
  - То, что требует проверки на физических устройствах (тач-свайпы, вибрация на iOS, читаемость шрифтов на 4K TV).

---

## 4. Сохранение целостности игровых режимов

Проект включает 4 активных режима (`MANIAC_VS_OPERATIVE`, `THIEF_HUNT`, `SECRET_SERVICE`, `LINE_UP`) и режим `TV Party`.
- Правка логики для одного режима не должна ломать остальные.
- Любое изменение сигнатур в `gameLogic.ts`, `gameReducer.ts` или `src/server/index.ts` требует обязательного прогона тестов всех режимов:
  - `src/utils/__tests__/maniac.test.ts`
  - `src/utils/__tests__/thiefHunt.test.ts`
  - `src/utils/__tests__/secretService.test.ts`
  - `src/utils/__tests__/duelLogic.test.ts`
  - `src/utils/__tests__/tvSessionFlow.test.ts`
