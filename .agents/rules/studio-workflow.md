# Правила работы AI-студии «Под подозрением (Prime Suspect)»

> Официальное название: **«Под подозрением (Prime Suspect)»**.  
> Все агенты обязаны следовать инструкциям из `.agents/studio/`.

## 1. Роль директора и подчинение
- Владелец проекта (Human Boss) принимает продуктовые, дизайнерские и архитектурные решения.
- AI-директор координирует команду, декомпозирует задачи, распределяет файлы и отчитывается на русском языке.

## 2. Безопасность репозитория и Git
- Строжайший запрет деструктивных команд: `git reset`, `git clean`, `git checkout .`, `git stash`, удаление веток, несогласованные коммиты и push.
- В репозитории находятся ценные незакоммиченные файлы — относиться к ним как к защищённым данным.
- Worktrees не используются до фиксации базового коммита релиза v1.0.0, так как они не переносят незакоммиченные файлы.
- Режим работы студии: последовательный с правилом «Один файл — один исполнитель».

## 3. Неизменяемые правила игры и дизайн-ограничения
- Портреты персонажей — силуэты без лиц.
- TV Party: телевизор — общее поле 5×5; смартфон — контроллер с окном 3×3.
- Маневр поля: циклический 1 клетка, строгий 2-этапный UX (ось/линия, затем направление). Без карт из руки.
- Фирменный биометрический слайдер кнопки «Быстрая игра» сохраняется.
- Zero Emoji: только векторные SVG-иконки.
- **Строгие визуальные запреты:**
  - Запрещено использовать кислотные цвета и превращать интерфейс в дешёвый неон.
  - Запрещено изменять карточки режимов, элементы действий и окантовки статусов без прямого разрешения владельца проекта.
  - Запрещено удалять или ухудшать удачные анимации.
  - Запрещено добавлять новые декоративные плашки, чипсы и бейджи без необходимости.

## 4. Независимый QA
- Никаких утверждений «всё работает» без терминальных логов `npm test` (все 46 файлов тестов / 295 тестов), `npx tsc --noEmit` и `npm run build`.
- QA Auditor независим от разработчика.
