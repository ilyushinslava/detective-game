# Дизайн-система Neo-Noir и визуальные инварианты

Данный документ описывает реальную дизайн-систему, цветовую гамму, типографику и инварианты компоновки интерфейса игры «Реквием: Последний выстрел».

---

## 1. Стилистическая концепция (Cyberpunk Neo-Noir)

Интерфейс оформлен в эстетике мрачного детективного нео-нуара:
- **Фоны:** глубокие тёмные тона (`#06070a`, `#080a0f`, `bg-black/60`, `bg-zinc-950/80`).
- **Стекломорфизм (Glassmorphism):** полупрозрачные плашки с эффектом размытия фона (`backdrop-blur-xl`, `backdrop-blur-sm`), тонкие световые границы (`border border-white/10`) и глубокие тени (`shadow-2xl`, `shadow-lg`).
- **Типографика:**
  - Основной текст: чёткий гротеск без засечек (`font-sans`, цвета `text-zinc-100`, `text-zinc-300`, `text-zinc-400`).
  - Координаты, таймеры, баланс, номера карт и технические метки: моноширинный шрифт (`font-mono`).

---

## 2. Цветовая палитра и акценты

1. **Базовая монохромная основа:**
   - Оттенки `zinc` (от `zinc-100` до `zinc-900`), `neutral`, `white`, `black`.
2. **Семантические акценты:**
   - **Красный (Угроза, Убийство, Маньяк):** `text-red-400`, `bg-red-950/40`, `border-red-500/40`, свечение `shadow-[0_0_10px_rgba(239,68,68,0.8)]`.
   - **Синий (Закон, Детектив, ТВ-эфир, Радар):** `text-blue-400`, `bg-blue-950/40`, `border-blue-500/40`, свечение `shadow-[0_0_10px_rgba(59,130,246,0.8)]`.
3. **Утверждённые исключения в коде:**
   - **Баланс и сокровища:** `Icons.Coin`, золото `amber-400`.
   - **Индикатор статуса сети:** зелёная точка `emerald-400` («В сети / ONLINE»).
   - **Позывные агентов («Секретная служба»):** тактические цвета резидентур (`SPY_COLORS`: Зенит, Дамаск, Филин, Вектор).
4. **Ограничение:** Не вводить случайные кислотные оттенки без согласования с владельцем проекта.

## 3. Критические инварианты интерфейса

### Инвариант стабильности сетки поля (Zero Board Shifting)
- Игровое поле 5×5 (или 6×6) должно сохранять стабильный размер и положение на экране.
- Нижняя панель действий (`ActionButtonsBar`) обязана находиться в изолированном flex-слоте с фиксированной высотой кнопок (`h-10`, `h-11`, `h-12`).
- Запрещено использовать хаотичный абсолютный или плавающий layout, из-за которого доска прыгает или сжимается при появлении подсказок или смене хода.

### Контракт поведения стрелок сдвига поля (Board Shift Arrows Contract)
1. **Кратковременный белый импульс:** Стрелка сдвига подсвечивается **исключительно белым цветом** (`bg-zinc-800 border-white/80 text-white shadow-[0_0_12px_rgba(255,255,255,0.5)] ring-1 ring-white/40`) и **строго на время нажатия (250 мс)**.
2. **Запрет залипания:** Запрещено постоянное (персистентное) свечение стрелки на основе `lastShift`. После завершения сдвига стрелка обязана вернуться в дефолтное нейтральное состояние (`bg-zinc-950/70 border-white/10 text-zinc-400`).
3. **Запрет цветных стилей:** Запрещено использование цветных стилей (blue, cyan, amber, red) для индикации стрелок сдвига — только монохромная белая вспышка.
4. **Блокировка обратного хода (Anti-Undo):** Противоположная стрелка, отменяющая ход соперника, отображается нейтральной иконкой `⊘` с `opacity-30 cursor-not-allowed` без какого-либо свечения.

### Использование иконок и эмодзи
- **Новые элементы интерфейса:** Для новых компонентов UI предпочтительны векторные SVG-иконки и соблюдение единого визуального стиля нео-нуара.
- **Существующие эмодзи:** Уже присутствующие в коде эмодзи (в журнале боевых логов `🎯`, `🔍`, `📡`, профиле игрока `🕵️‍♂️`, кнопке блокнота `📋` и панели разработчика `DevPanel`) допустимы и легитимны.
- **Регламент изменений:** Удаление или замена существующих эмодзи не является обязательной задачей и требует отдельного решения владельца проекта.
- **Ограничения:** Не вводить новые искусственные дизайн-ограничения без предварительного подтверждения владельца.

### Мобильный контроллер игрока (`MobileControllerView.tsx`)
- **Пространственная мини-карта 3×3 («Ваши соседи»):** персонажи вокруг игрока отображаются строго в соответствии с их физическим положением на доске (сверху, снизу, сбоку, диагонали). Для позиций за границей доски 5×5 отображаются заглушки `[КРАЙ ПОЛЯ]`.
- **Схема сдвига линий:** выбор ряда/столбца на шаге 2 отображается в виде 5 наглядных графических полос (горизонтальных для строк, вертикальных для столбцов).
- **Кнопка завершения хода:** выделенная, крупная, во всю ширину внизу экрана.

### Экран телевизора (`TvBoardView.tsx`)
- Компоновка в 3 колонки:
  - **Левая:** карточка текущего игрока + публичный блок «ДОСТУПНЫЕ ДЕЙСТВИЯ».
  - **Центр:** игровое поле 5×5 с анимациями сдвига Framer Motion.
  - **Правая:** блок «ВЫБРАННАЯ ЛИНИЯ» (живой предпросмотр маневра с телефона) + протокол событий.
- **Поддержка ТВ-пульта (D-Pad):** обработка клавиш `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Enter`, `Escape` и Android TV keycodes (`19..23, 66, 4`).
