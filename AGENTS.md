# Инструкция для ИИ-ассистентов и разработчиков

Данный файл содержит строгие правила работы с кодовой базой проекта «Город грехов».

## 1. Сборка и тестирование

Перед предложением масштабных изменений убедитесь, что они не ломают сборку и тесты:

- **Запуск тестов:** `npm run test` (используется Vitest). Тесты покрывают ядро логики (`gameLogic.test.ts`, `aiLogic.test.ts`).
- **Сборка проекта:** `npm run build` (выполняет `tsc && vite build`).

## 2. Ограничения на рефакторинг

- **ЗАПРЕЩЕНО** выполнять неконтролируемый рефакторинг публичных интерфейсов (`src/types/game.ts`, `src/types/multiplayer.ts`).
- **ЗАПРЕЩЕНО** изменять схемы данных Firebase и правила безопасности без явного согласования с Technical Lead.
- **ЗАПРЕЩЕНО** отключать проверки TypeScript (`@ts-ignore`) или правила ESLint для быстрого обхода ошибок.

## 3. Формат внесения изменений

Все предложения по изменению кода должны предоставляться ИСКЛЮЧИТЕЛЬНО в формате точечных замен:

```text
ФАЙЛ: путь/к/файлу.ts
НАЙТИ:
<точный кусок старого кода>
ЗАМЕНИТЬ НА:
<новый код>
Не переписывайте файлы целиком, если требуется изменить только одну функцию.

## 4. UI и UX ограничения

ЗАПРЕЩЕНО использовать нативные браузерные диалоги: alert(), confirm(), prompt().
Для уведомлений используйте компонент <Toast /> (src/components/Toast.tsx).
Для модальных окон используйте существующие паттерны (например, RoleRevealModal.tsx, GameOverModal.tsx) с поддержкой Tailwind CSS и Framer Motion.
```
