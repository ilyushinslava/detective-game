# PROJECT_CONTEXT.md — Контекст проекта «Реквием: Последний выстрел»

> **Проект:** «Реквием: Последний выстрел» (The Wicked City)  
> **Жанр:** Детективная киберпанк-стратегия (Web, PWA, TV Party, Android)  
> **Текущая ветка:** `feature/tv-party-enhancements`

---

## 1. Стек технологий и зависимости

- **Frontend:** React 18.3.1, TypeScript 5.4.5, Vite 5.2.11, Tailwind CSS 3.4.3, Framer Motion 11.1.7.
- **PWA:** `vite-plugin-pwa` 2.0.0 (Workbox, 95 прекэшированных ассетов, офлайн-режим).
- **Сетевой бэкенд:** PartyKit 0.0.115 (WebSocket), `server-standalone.mjs` (автономный Node.js runner с динамическим импортом через `jiti` на Render).
- **Хранилище:** IndexedDB (`src/utils/storage.ts`, база `requiem_game_db`, хранилище `key_val`) с автомиграцией из `localStorage`.
- **Звук и тактильный отклик:** Web Audio API (программный синтез в `audio.ts` без внешних mp3), `navigator.vibrate` (в `haptics.ts`).
- **Тестирование:** Vitest 1.6.1, JSDOM 29.1.1, React Testing Library 16.3.3 (42 тест-сьюта, 255 тестов).

## 2. Игровые режимы и ключевые инварианты

1. **«Почерк убийцы» (`MANIAC_VS_OPERATIVE`):**
   - Маньяк устраняет жертв строго по открытой очереди контракта (`victimList`).
   - Радиус слышимости выстрела — сектор 3×3. Если Сыщик вне сектора — следствие в тупике.
   - Ошибка следствия не приводит к мгновенному поражению (Сыщик раскрывает свою позицию).
   - Маньяк может совершить побег (`ESCAPE_DISGUISE`), приняв новое обличье.
2. **«Оцепление» (`THIEF_HUNT`):**
   - Вор похищает сокровища (цель: 8 жетонов) без убийств жителей.
   - Полиция выставляет патрули оцепления, блокируя сдвиги строк/колонок.
   - Смена маски Вора осуществляется из руки.
3. **«Директива Ноль» (`SECRET_SERVICE`):**
   - Шпионские дуэли: перекрестный опрос свидетелей в радиусе 3×3.
   - Порог победы: 3 трофея в дуэли (2 игрока), 4 при 3 игроках, 3 при 4+ игроках.
4. **«Очная ставка» (`LINE_UP`):**
   - Дедуктивная матрица признаков персонажей (`src/components/duel/DuelScreen.tsx`).

## 3. Архитектура экранов и сетевые клиенты

- `App.tsx` маршрутизирует интерфейс по параметрам URL:
  - `?clientType=TV_DISPLAY&room=XXXXX` — экран телевизора (`TvBoardView.tsx`, `TvLobbyView.tsx`).
  - `?clientType=CONTROLLER&room=XXXXX` — мобильный пульт (`MobileControllerView.tsx`).
  - Обычный клиент — главное меню (`MainMenu.tsx`), игровое поле 5×5 (`GameScreen.tsx`), Академия (`TutorialScreen.tsx`), профиль (`ProfileScreen.tsx`), лобби столов (`TablesScreen.tsx`).
- **Безопасность сервера (`src/server/index.ts`):**
  - Авторитетная валидация ходов и прав хоста.
  - Маскирование секретов: `maskStateForPlayer` и `maskStateForTv` скрывают чужие роли, колоды и будущие цели.
  - Сокеты ТВ (`TV_DISPLAY`) не имеют права слать игровые экшены.
