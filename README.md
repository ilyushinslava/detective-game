> Пошаговая детективная стратегия в стиле Neo-Noir с механикой социальной дедукции, скрытых ролей и динамического поля 5×5.

## 🎮 Об игре

Действие разворачивается в закрытом ночном мегаполисе. На поле 5×5 перед игроками находятся 25 жителей. Игроки выполняют маневры рядов и столбцов, опрашивают свидетелей и собирают улики в радиусе 3×3, пытаясь вычислить тайную личность соперника.

### Игровые режимы:
1. **«Почерк убийцы» (`MANIAC_VS_OPERATIVE`):** Асимметричная охота за 4 жертвами против детектива с колодой улик.
2. **«Оцепление» (`THIEF_HUNT`):** Домушник ворует 8 сокровищ и меняет маски против шефа полиции и 2 патрульных офицеров.
3. **«Директива «Ноль»» (`SECRET_SERVICE`):** Контрразведка для 2–8 игроков со сбором компромата и перекрёстным опросом на радаре 3×3.
4. **«Очная ставка» (`LINE_UP` / Дуэль) `[ЗАМОРОЖЕН / В РАЗРАБОТКЕ]`:** Режим скрыт из активного меню и турнирной ротации; технический долг ожидает отдельного спринта редизайна.

### Режим TV Party (Салонный формат / Jackbox-модель):
- **Телевизор (Android TV / ПК):** Большой экран с публичным полем 5×5, доступными действиями, живым предпросмотром маневров, D-Pad навигацией по меню паузы и кнопкой «В МЕНЮ» в статус-баре.
- **Смартфоны игроков:** Приватный контроллер с пространственной мини-картой соседей 3×3, 2-этапным маневром линий поля, экраном ожидания («режим радиомолчания»), кнопкой завершения хода и аварийным выходом.
- **Подключение устройств:** Авторизация в `ControllerConnectView` по детерминированному 7-символьному коду Морзе со звуковым телеграфным ключом на оригинальных сэмплах `public/sounds/`, либо прямое сканирование QR-кода встроенной камерой (5-значный PIN полностью удалён).

### Академия детективов (Обучение v2):
- **3 канонических дела (ровно 11 шагов):** логичные сюжетные сценарии по активным режимам (Дело 1 — 5 шагов, Дело 2 — 4 шага, Дело 3 — 2 шага с наградой +500 монет).
- **Zero-Jump вёрстка:** жёсткие 4 слота экрана `h-[100dvh]` (шапка `h-14`, брифинг `h-[84px]`, неподвижная доска `flex-1`, панель действий `h-[64px]`), устранившие любые скачки поля при переключении шагов.
- **Объединённый шаг действия (`CARD_ACTION`):** выбор целевой карты сразу активирует и подсвечивает кнопку действия в нижней панели.

## 🛠 Технологический стек

- **Frontend:** React 18, TypeScript (строгий режим `noImplicitAny`, `strictNullChecks`), Tailwind CSS, Framer Motion.
- **Аудиосистема (`soundManager`):** 2-канальный аудиоконтроллер (UI-канал и Action-канал) с 25 оригинальными сэмплами в `public/sounds/`, микро-дебаунсом 70 мс и автоматическим подавлением наложений. Процедурный синтез `createOscillator` полностью исключён.
- **Интернационализация (i18n):** Двуязычный интерфейс (RU / EN) с переключением на лету и типизацией словарей.
- **Архитектура главного меню:** Декомпозиция на `LobbyGrid` (сетка 3 карточек: PVE, PVP, широкий TV Party), `ModeCard` (чистый outline-стиль) и `NetworkSidebar` (Inset Terminal Deck). Нижний бар на 3 вкладки («Главное меню», «Сеть», «Досье») с полной изоляцией мультиплеера.
- **Профиль и достижения:** Модульная система из 18 достижений (`achievements.ts`, `achievementEngine.ts`), всплывающие уведомления `AchievementToast` и вкладка достижений в профиле детектива.
- **PWA и оптимизация бандла:** `vite-plugin-pwa` с уведомлением о новой версии `PwaUpdateToast` (`registerType: "prompt"`), гранулярный код-сплиттинг `manualChunks` (`vendor-react`, `vendor-supabase`, `vendor-ui`, `vendor-network`, `vendor-qr-scanner`, `tv-party`), изоляция `DevPanel` (0 байт в продакшене), прекэш 105 ассетов (~5.0 МБ для полной автономности офлайн).
- **Backend / Мультиплеер:** PartyKit WebSocket сервер + Standalone Node.js runner (`ws` + HTTP) на Render.
- **Облачная база данных и профили:** Supabase (PostgreSQL, Row Level Security, RPC `record_match_result` с защитой от спидхака) с оффлайн-фоллбэком. Авторизация по логину/паролю без сбора персональных данных (Email).
- **Хранилище данных:** Безопасный фасад `storage.ts` (`safeLocalStorage`, `safeSessionStorage`, IndexedDB `requiem_game_db`) с защитой от сбоев в приватных вкладках браузера.
- **Нативная интеграция:** Capacitor 8 (`@capacitor/haptics` для тактильного отклика на смартфонах).
- **Тестирование и CI:** Vitest + React Testing Library (95 тест-сьютов, 618 тестов, 100% pass) + автоматический GitHub Actions CI (`.github/workflows/ci.yml`).

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск frontend в режиме разработки
```bash
npm run dev
# Сервер разработки Vite будет доступен по локальному адресу (по умолчанию: http://localhost:5173/)
```

### 3. Запуск backend / WebSocket сервера

- **Локальный PartyKit сервер разработки:**
  ```bash
  npm run party:dev
  # запускает локальный PartyKit на порту 1999
  ```
- **Автономный Node.js сервер (Standalone):**
  ```bash
  npm run server:standalone
  # запускает server-standalone.mjs на порту process.env.PORT || 1999
  ```
- **Одновременный запуск frontend и backend одной командой:**
  ```bash
  npm run dev:all
  ```

### 4. Проверки и быстрая верификация

Во время разработки используйте правила быстрой верификации без лишних циклов ожидания:
```bash
# Таргетная проверка типов и затронутых тестов
npx tsc --noEmit && npx vitest run --changed

# Запуск конкретного тестового сьюта
npx vitest run src/components/__tests__/tutorialFullFlow.test.tsx

# Полный сьют тестов (финальный локальный прогон)
npx vitest run
```

### 5. Сборка для production
```bash
npm run build
# Компилирует TypeScript и выполняет оптимизированную сборку Vite в папку dist/
```

### 6. Оптимизация медиа-ресурсов
```bash
npm run optimize:assets
# Сжимает портреты персонажей и фоновые изображения для уменьшения прекэша PWA
```
