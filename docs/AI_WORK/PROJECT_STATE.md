# Краткий паспорт проекта: Реквием: Последний выстрел

## 1. Назначение и технологии

- **Тип приложения:** PWA/SPA (Single Page Application) с авторитетным WebSocket-сервером.
- **Стек (Frontend):** React 18, TypeScript, Vite, Tailwind CSS, Framer Motion.
- **Стек (Backend):** PartyKit (WebSocket).
- **Сборка:** Vite, TypeScript (tsc).

## 2. Структура архитектуры

- **Игровое ядро (`src/utils/gameLogic.ts`, `gameReducer.ts`):** Чистые функции для детерминированного изменения состояния. Поддерживает поля 5x5, 6x6, 7x7.
- **Сетевой слой (`src/server/index.ts`, `src/utils/partyPeer.ts`):** Сервер управляет лобби, пересылает действия (GameAction) и рассылает замаскированное состояние (`SYNC_STATE`). Клиент отправляет действия через `partyService.sendAction`.
- **UI Компоненты:** Единый источник истины для поля (`GameBoard.tsx`), карточек (`CharacterCard.tsx`) и кнопок (`ActionButtonsBar.tsx`, `useGameActions.ts`).
- **ТВ-режим:** Маршрутизация через параметры URL (`?clientType=TV_DISPLAY` / `CONTROLLER`). Разделенные компоненты отображения (`TvBoardView.tsx`) и управления (`MobileControllerView.tsx`).

## 3. Игровые режимы

1. **Схватка (SKHVATKA):** Классическая дуэль (Бандит vs Инспектор).
2. **Маньяк против оперативника (MANIAC_VS_OPERATIVE):** Охота по фиксированному списку жертв (4 цели).
3. **Охота на грабителя (THIEF_HUNT):** Сбор 10 сокровищ без убийств.
4. **Секретная служба (SECRET_SERVICE):** Командный или дуэльный шпионаж со сбором трофеев.
5. **Очная ставка (LINE_UP):** Логическая дуэль с вопросами по характеристикам (25 уникальных карт).

## 4. Источник истины игрового состояния

- **Глобальный стейт:** `GameState` (определен в `src/types/game.ts`), управляется через `gameReducer.ts`.
- **Серверная авторитетность:** Сервер `index.ts` проверяет базовые системные события (`MATCH_STARTED`, `RESTART_GAME`), но игровая логика и проверка правил хода полагаются на детерминизм `gameReducer`.
- **Скрытые данные:** Сервер фильтрует состояние перед отправкой (маскирование `killerSecretId`, `detectiveSecretId`, `killerHand` и др.) в зависимости от роли клиента.

## 5. Сетевой протокол

- События: `SYNC_STATE`, `ROOM_STATUS`, `OPPONENT_LEFT`, `LINE_PREVIEW`, `ALL_PLAYERS_READY`.
- Восстановление сессии: `sessionStorage` хранит `mp_session` (для браузера) и `tv_controller_client_id` (для ТВ-контроллеров).

## 6. Основные ограничения

- Отсутствие серверного таймера/game loop (сервер реагирует только на входящие WebSocket-сообщения).
- Запрет на использование эмодзи в UI (только SVG-иконки).
- Палитра UI строго ограничена (Noir: zinc, red, blue).

## 7. Статусы проверки сведений
