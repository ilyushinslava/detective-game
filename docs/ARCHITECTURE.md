# Архитектура проекта: «Реквием: Последний выстрел»

> **Статус:** Актуальная техническая спецификация системы  
> **Стек:** React 18, TypeScript, Tailwind CSS, Framer Motion, PartyKit WebSocket, Vite, IndexedDB

---

## 1. Обзор архитектурных уровней

Архитектура построена на принципах **Single Source of Truth (Единый источник истины)**, **детерминированного редьюсера состояний** и **авторитетного сервера**:

```
┌────────────────────────────────────────────────────────────────────────┐
│                          КЛИЕНТСКИЙ СЛОЙ (React)                       │
├──────────────────────────┬──────────────────────────┬──────────────────┤
│         App.tsx          │   Экран игры GameScreen  │    TvBoardView   │
│  (Роутинг, Вкладки, Сессия)│   (Поле 5×5, Панель UI)   │    (Экран ТВ)    │
├──────────────────────────┴──────────────────────────┼──────────────────┤
│             MobileControllerView.tsx                │   DuelScreen.tsx │
│        (Пульт: вырезка 3×3, визард сдвига)          │  (Очная ставка)  │
└──────────────────────────┬──────────────────────────┴──────────────────┘
                           │ Custom Hooks (useGameActions, useMultiplayer)
                           ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   ИГРОВОЕ ЯДРО (Shared Core Logic)                     │
├────────────────────────────────────────────────────────────────────────┤
│  gameReducer.ts  ── Чистая функция вычисления следующего GameState     │
│  gameLogic.ts    ── Геометрия 5×5, метрика 3×3, сдвиги, Anti-Undo     │
│  duelLogic.ts    ── Каталог признаков и дедуктивная матрица дуэли      │
│  aiLogic.ts      ── Эвристические алгоритмы автономных ботов           │
└──────────────────────────┬─────────────────────────────────────────────┘
                           │ WebSocket Protocol (JSON-сообщения)
                           ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   СЕРВЕРНЫЙ СЛОЙ (PartyKit / Render)                   │
├────────────────────────────────────────────────────────────────────────┤
│  GameRoomServer (src/server/index.ts):                                 │
│  - Управление комнатами и реестр лобби (/rooms, /lobby)                │
│  - Аутентификация сессий через crypto-токены (authToken)               │
│  - Серверная валидация прав хоста и очередности ходов                  │
│  - Маскирование секретов: maskStateForPlayer() и maskStateForTv()      │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Клиентский слой (Frontend)

### Роутинг и экраны в `App.tsx`
Приложение функционирует как единое SPA, где экран выбирается на основе параметров URL и внутреннего состояния:
1. **Параметры URL:**
   - `?clientType=TV_DISPLAY&room=XXXXX` — автоматически переводит приложение в режим **главного экрана телевизора**.
   - `?clientType=CONTROLLER&room=XXXXX` — переводит телефон в режим **мобильного контроллера**.
2. **Основные экраны:**
   - `SplashScreen.tsx` — заставка загрузки с анимацией.
   - `MainMenu.tsx` — главное меню (выбор одиночного режима, мультиплеера, дуэли, ТВ-вечеринки и обучения).
   - `TablesScreen.tsx` — список открытых публичных сетевых столов со ставками.
   - `ProfileScreen.tsx` — личный профиль детектива, статистика побед, уровень и баланс.
   - `GameScreen.tsx` — стандартное игровое поле 5×5 с карточками персонажей и нижней панелью действий.
   - `DuelScreen.tsx` — специализированный экран дедуктивной дуэли («Очная ставка»).
   - `TvBoardView.tsx` — 3-колоночный экран для телевизора с поддержкой пульта D-Pad.
   - `MobileControllerView.tsx` — специализированный мобильный пульт с пространственной мини-картой соседей 3×3 и пошаговым визардом сдвига.

### Кастомные хуки и сервисы (Hooks & State Integration)
Хуки разделены по двум директориям в зависимости от их назначения:

1. **Игровые хуки (`src/hooks/`):**
   - `src/hooks/useGameActions.ts` — единая точка диспетчеризации игровых действий (сдвиг, атака, опрос, обвинение).
   - `src/hooks/useBoardVisuals.ts` — расчёт визуальных состояний карточек (соседство, активная цель, радар, подсветка сдвигаемой линии).
   - `src/hooks/useGameTimer.ts` — таймер хода с автоматическим завершением при истечении времени.
   - `src/hooks/useAiTurn.ts` — координация задержки и хода ИИ-бота в одиночном режиме.
   - `src/hooks/useGameLog.ts` — форматирование и хранение тактического журнала событий.
   - `src/hooks/useMatchEndHandler.ts` — обработка финала матча и переход к результатам.

2. **Сетевые и профильные хуки (`src/utils/`):**
   - `src/utils/useMultiplayer.ts` — хук связки локального React-состояния с сетевым клиентом PartyKit.
   - `src/utils/usePlayerProfile.ts` — хук управления профилем игрока, статистикой побед и начислением наград.
   - `src/utils/partyPeer.ts` — синглтон управления WebSocket-соединением (`PartyService`).

## 3. Серверная архитектура (PartyKit & Standalone)

Серверная часть спроектирована универсально: она может работать как в бессерверной среде Cloudflare/PartyKit, так и в стандартном контейнере Node.js.

### Двойной запуск сервера:
1. **Режим разработки (PartyKit CLI):**
   ```bash
   npm run party:dev # или npm run server:start
   ```
2. **Автономный сервер для облака (Render):**
   `server-standalone.mjs` — независимый Node.js runner на библиотеке `ws` и HTTP, использующий `jiti` для динамической загрузки `src/server/index.ts` без предварительной компиляции. Развёрнут на Render (`detective-game-haxi.onrender.com`).

### Жизненный цикл комнаты (`ServerRoomState`):
- `EMPTY` — комната создана, ожидает хоста.
- `WAITING` — хост подключился, комната зарегистрирована в реестре `publicRoomsRegistry` и ждёт второго игрока/телевизор.
- `READY_TO_START` — требуемое количество участников набрано, ожидается подтверждение готовности.
- `PLAYING` — матч активен, сервер валидирует и диспатчит действия в `gameReducer`.
- `FINISHED` — матч завершён, зафиксирован победитель.

## 4. Безопасность и античит (State Masking)

Перед трансляцией состояния клиентам через WebSocket сервер выполняет обязательную фильтрацию:

1. **`maskStateForPlayer(state, role, isHost)`:**
   - Скрывает секретные ID персонажей соперника (`killerSecretId` / `detectiveSecretId` / чужие `spies[i].secretId`).
   - Очищает руки карт оппонента (`detectiveHand` / `killerHand`).
   - Очищает колоду улик (`evidenceDeck`).
   - Маскирует будущие цели маньяка в очереди `victimList` строками `"UNKNOWN"`, оставляя открытой только текущую цель `[0]`.
2. **`maskStateForTv(state)`:**
   - Полностью очищает все секретные роли, колоды и руки, так как экран ТВ публичен.
   - Оставляет только общее поле 5×5, статус хода, открытые жетоны и протокол действий.
3. **Защита сокета TV_DISPLAY:**
   - Сервер блокирует любые игровые действия, если они отправлены с соединения ТВ.

## 5. Хранилище данных (Storage Architecture)

Файл `src/utils/storage.ts` реализует надёжную двухуровневую систему сохранения данных:
1. **Основное хранилище:** `IndexedDB` (база `requiem_game_db`, хранилище `key_val`). Обеспечивает асинхронную надёжную работу на мобильных устройствах без ограничений `localStorage`.
2. **Автоматическая миграция:** При первом запуске модуль проверяет наличие старых данных в `localStorage` по ключам `crime_city_profile`, `crime_city_tutorial`, `crime_city_haptics`, переносит их в IndexedDB и безопасно очищает устаревшие записи.
3. **Фолбек:** Если IndexedDB недоступна (например, в приватном режиме Safari), модуль плавно переключается на безопасный in-memory / localStorage фолбек.

## 6. Звук, вибрация и PWA

- **Звуковая подсистема (`audio.ts`):** Реализована через Web Audio API с программным синтезом звуков (выстрел, сдвиг, сирена, клики) без обязательной загрузки тяжёлых внешних mp3-файлов.
- **Тактильный отклик (`haptics.ts`):** Использует `navigator.vibrate` с набором тактильных паттернов (лёгкий клик, предупреждение, успех, тревога) и безопасной проверкой поддержки браузером.
- **PWA (Progressive Web App):** Настроен через `vite-plugin-pwa` в `vite.config.ts`. Прекэширует 93 ключевых ресурса (общий объём всего ~5.1 МБ), обеспечивая мгновенный запуск офлайн и возможность установки игры на рабочий стол смартфона или Android TV.
