# Архитектура проекта

## 1. Технологический стек

- **Frontend:** React 18, TypeScript, Vite.
- **Стилизация:** Tailwind CSS.
- **Анимации:** Framer Motion.
- **Backend / Мультиплеер:** PartyKit WebSocket (с поддержкой Standalone HTTP/WS runner для облачных платформ).

## 2. Сетевой слой и мультиплеер (PartyKit)

Сетевая архитектура построена на авторитетном сервере комнат и клиентском синглтоне управления соединениями.

- **Авторитетный сервер комнат (`GameRoomServer` в `src/server/index.ts`):**
  - Управляет жизненным циклом комнаты (`status`: `EMPTY`, `WAITING`, `READY_TO_START`, `PLAYING`, `FINISHED`).
  - Ведёт реестр открытых лобби (`publicRoomsRegistry`) и обрабатывает HTTP-запросы (`/rooms`, `/parties/main/lobby`).
  - Обрабатывает подключение клиентов (`onConnect`), распределяет роли и инициирует игровое состояние через `createInitialState`.
  - Принимает клиентские действия (`onMessage`), валидирует право хода и очерёдность, после чего вычисляет следующее состояние через детерминированный `gameReducer`.
  - **Маскирование секретов (`maskStateForPlayer`):** перед отправкой клиентам сервер фильтрует состояние, скрывая секретные идентификаторы персонажей оппонента (в зависимости от роли и стороны) для предотвращения читерства.
  - Синхронизирует клиентов широковещательными событиями `SYNC_STATE`, `ROOM_STATUS`, `OPPONENT_LEFT`.

- **Клиентский сервис (`PartyService` в `src/utils/partyPeer.ts`):**
  - Управляет подключением по WebSocket (`ws://` / `wss://`) к хосту PartyKit или автономному серверу.
  - Автоматически определяет хост (`VITE_PARTYKIT_HOST`, локальный `localhost:1999` или продакшен-инстанс).
  - Проксирует отправку действий (`sendAction`) и распределяет входящие сообщения по коллбэкам (`onSyncState`, `onRoomStatus`, `onAllPlayersReady`, `onPresenceChanged`).
  - Получает список доступных комнат через `fetchPublicRooms()`.

## 3. Управление состоянием

- **Игровое ядро:** Состояние игры (`GameState`) обновляется исключительно через чистую функцию `gameReducer` (`src/utils/gameReducer.ts`), которая детерминированно вычисляет новое состояние на основе текущего стейта и `GameAction`.
- **Игровая логика:** Собрана в `src/utils/gameLogic.ts`. Включает расчет соседства 3×3, циклические сдвиги линий сетки, валидацию инварианта Anti-Undo и проверки победы.
- **Профиль игрока:** Управляется хуком `usePlayerProfile.ts` с персистентным хранением прогресса в `localStorage`.

## 4. Взаимодействие UI и логики

- **Компоненты:** Компонент `App.tsx` управляет отображением экранов, интеграцией хука мультиплеера `useMultiplayer.ts`, модальными окнами и передаёт актуальный срез данных в `GameBoard.tsx`, `CharacterCard.tsx` и панели управления.
- **ИИ-боты:** Логика автономных соперников реализована в `src/utils/aiLogic.ts` и координируется хуком `useAiTurn.ts`. При игре против бота ход рассчитывается локально и диспатчится в редьюсер с сохранением единого формата действий.
