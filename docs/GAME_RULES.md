# Официальный свод правил: «Реквием: последний выстрел» (The Wicked City)

## 1. Базовые математические инварианты поля

- **Игровая сетка:** Поле фиксированного размера 5x5 клеток (25 уникальных персонажей; для расширенного режима 5 игроков — 6x6).
- **Метрика соседства:** Две клетки считаются соседними, если расстояние между ними по строкам и столбцам не превышает 1 (`dr <= 1 && dc <= 1`, исключая саму клетку). Каждый персонаж внутри поля имеет до 8 соседей (по горизонтали, вертикали и диагонали). Через границы поля механики соседства не замыкаются.
- **Маневр линий:** Один раз за свой ход активный игрок может выполнить маневр любого ряда по горизонтали или колонки по вертикали на 1 клетку. Персонаж, вышедший за пределы поля, циклически возвращается с противоположной стороны линии.
- **Поведение стрелок маневра поля (Board Shift Arrows Contract):**
  1. Стрелка маневра подсвечивается **исключительно белым цветом** и **строго на время нажатия (250 мс)** (`bg-zinc-800 border-white/80 text-white shadow-[0_0_12px_rgba(255,255,255,0.5)] ring-1 ring-white/40`).
  2. Запрещено постоянное (персистентное) свечение стрелки на основе `lastShift`. После завершения маневра стрелка обязана вернуться в дефолтное нейтральное состояние.
  3. Запрещено использование цветных стилей (blue, cyan, amber, red) для индикации стрелок маневра — только монохромная белая вспышка.
- **Правило Anti-Undo:** Запрещено выполнять обратный маневр того же ряда/колонки в противоположном направлении, отменяющий действие соперника предыдущего хода. Противоположная заблокированная стрелка отображается нейтральной иконкой `⊘` с `opacity-30 cursor-not-allowed` без какого-либо свечения.
- **Зачистка:** Специальное действие перестроения при накоплении ликвидированных персонажей. Все выбывшие карты переносятся в конец сетки, уплотняя активную зону живых подозреваемых.
- **Инвариант колоды:** Все карты, находящиеся в колоде улик (`evidenceDeck`), на руках игроков или назначенные секретными ролями, гарантированно присутствуют на игровом поле.

## 2. Режим «Почерк убийцы» (MANIAC_VS_OPERATIVE)

Серийная охота по закрытому списку жертв (2 игрока).

- **Победа Маньяка:** Ликвидировать 4 цели из фиксированного списка жертв **ИЛИ** устранить Оперативника.
- **Победа Оперативника:** Раскрыть личность Маньяка действием «Задержание».
- **Действия Маньяка:**
  - **Ликвидация:** Устранить персонажа в радиусе соседства 3×3. Маньяк может атаковать любого соседнего жителя, но победный прогресс засчитывается исключительно при устранении открытой цели из списка жертв.
  - **Зачистка:** Переместить ликвидированных персонажей в конец поля для уплотнения сетки.
  - **Конспирация:** При наличии минимум 2 карт в колоде Маньяк скрытно перебирает резерв до первой живой и неоправданной личности. В список жертв в качестве штрафа добавляется +1 цель.
- **Действия Оперативника:**
  - **Проверка алиби:** Оперативник разыгрывает карту улик из руки на поле. Проводится проверка Маньяка на соседство 3×3, невиновный получает постоянный статус «Алиби», а Оперативник добирает новую карту из колоды.
  - **Задержание:** Обвинить соседнего персонажа. Ошибка не сокращает список жертв Маньяка: Оперативник теряет ход, а ошибочно проверенный персонаж получает статус «Алиби».
- **Особенности очереди и атак:**
  - Список жертв строго фиксирован: 4 карты, автопополнения из колоды нет.
  - После ликвидации цели очередь переходит к следующей жертве списка.
  - При любой ликвидации невиновного жителя проводится автоматический опрос свидетелей: общий радар сообщает, находится ли Оперативник в радиусе 3х3 вокруг жертвы.
- **Жизни и алиби Оперативника:**
  - Оперативник держит в руке 3 карты улик. При ранении Оперативник обязан принять личность одной из карт с руки. Если карт в руке не осталось — Оперативник погибает.

## 3. Режим «Оцепление» (THIEF_HUNT)

Дерзкий домушник против полицейского оцепления (2 игрока).

- **Победа Грабителя:** Похитить 8 сокровищ (совершить 8 успешных краж).
- **Победа Полиции:** Задержать текущую активную личность Грабителя.
- **Особенности регламента:**
  - Персонажи не погибают, поле не очищается действием «Зачистка».
  - У Полиции 1 тайный шеф и 2 открытых патрульных офицера на доске.
  - У Грабителя стартовая рука из 3 карт масок.
- **Действия Грабителя:**
  - **Кража:** Похитить сокровище у соседа или на своей клетке. Каждая клетка может быть ограблена только один раз (помечается жетоном монеты).
  - **Конспирация:** Моментально сменить текущую личность на одну из масок в руке без использования колоды. Старая личность возвращается в руку.
- **Действия Полиции:**
  - **Вызов патруля:** Заменить одного из патрульных картой из колоды. Пользуясь суматохой пересменки, Грабитель забирает +1 сокровище.
  - **Задержание:** Обвинить клетку рядом со своей тайной личностью **ИЛИ** рядом с любым из открытых патрульных.

## 4. Режим «Директива "Ноль"» (SECRET_SERVICE)

Контрразведывательная операция резидентур.

- **Действия Агентов:**
  - **Разоблачение:** Объявить соседнюю клетку. Если в ней находится тайная личность соперника — агент разоблачается, отдает трофей разоблачителю и получает новое прикрытие (`nextSecretId`) из резерва колоды. Союзников разоблачать запрещено.
  - **Опрос свидетелей:** Агент выбирает целевую клетку. Все игроки (включая активного), чьи тайные личности находятся в радиусе 3х3 вокруг цели, обязаны подтвердить контакт на общем радаре.
  - **Зачистка:** Уплотнение сетки выбывших резидентов при накоплении раскрытых ячеек.
- **Цели по трофеям (разоблаченным вражеским резидентам):**
  - **2 игрока (Дуэль):** сетка 5×5, цель — **3 трофея**.
  - **3 игрока:** сетка 5×5, цель — **4 трофея**.
  - **4 игрока:** сетка 5×5, цель — **3 трофея**.
  - **5 игроков:** сетка 6×6, цель — **3 трофея**.
  - **6 игроков (ТВ / Команды 3×2):** цель — **3 трофея**.
  - **8 игроков (ТВ / Команды 4×2):** цель — **3 трофея**.
  - **9 игроков (ТВ / Команды 3×3):** цель — **4 трофея**.
- **Позывные агентов:** Зенит (Красный), Дамаск (Синий), Филин (Бордовый), Вектор (Изумрудный).

## 5. Режим «Очная ставка» (LINE_UP / DUEL)

Интеллектуальная детективная дуэль на дедукцию (2 игрока).

- **Действия Дуэлянтов:**
  - **Вопрос:** Выбрать вопрос из каталога («Внешность», «Одежда», «Аксессуары») для проверки признаков тайной личности соперника. Ответ («ДА» или «НЕТ») заносится в общую историю дуэли.
  - **Обвинение:** Указать на подозреваемого. Точное совпадение — немедленная победа; ошибка приносит **+1 штрафное очко**, цель фиксируется в списке отклоненных, ход переходит оппоненту.
- **Колода дуэли:** Строго фиксированный пул из 25 персонажей (`DUEL_CHARACTERS`), обладающих набором дискретных признаков (пол, прическа, головной убор, очки, элементы одежды, аксессуары).
- **Фильтрация кандидатов:** Метод логического исключения на основе ответов.
- **Тай-брейк (8 минут):**
  1. Наименьшее число штрафных очков.
  2. Наименьшее число оставшихся кандидатов.
  3. Ничья при полном равенстве показателей.
