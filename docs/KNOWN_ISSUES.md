# Известные проблемы и технический долг

## 1. Firebase Security Rules

- **Статус:** Правила безопасности написаны и сохранены в `database.rules.json`.
- **Проблема:** Их необходимо вручную перенести и применить в консоли Firebase (Firebase Console -> Realtime Database -> Rules), так как автоматический деплой правил через CI/CD пока не настроен.

## 2. Недоступные режимы игры

- **Статус:** Режимы `EUROPOL_VS_OPG` и `SPANISH_HEIST` отображаются в UI с флагом `isAvailable: false`.
- **Проблема:** В `gameLogic.ts` присутствуют заглушки и базовые функции для этих режимов (например, `plantBomb`, `applyShield`, `crackVault`), но полноценный игровой цикл и ИИ для них еще не реализованы.

## 3. Экономика и магазин

- **Статус:** Находится в бета-режиме.
- **Проблема:** Данные профиля (деньги, опыт, ранг) хранятся исключительно в `localStorage` (`usePlayerProfile.ts`). При очистке кэша браузера прогресс теряется. В будущем требуется миграция профилей в Firebase Firestore/RTDB. Магазин (вкладка SHOP) отключен.

## 4. Сборка Vite

- **Статус:** При выполнении `npm run build` возникает предупреждение о размере бандла.
- **Проблема:** Итоговый чанк превышает рекомендуемый лимит в 500 кБ. Требуется настройка `manualChunks` в `vite.config.ts` для разделения вендорных библиотек (React, Firebase, Framer Motion) и кода приложения.
