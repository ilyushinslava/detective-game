# PROJECT_MASTER_DOC: «Реквием: Последний выстрел» (The Wicked City)

## 1. Архитектура и стек технологий

- **Frontend:** React 18, TypeScript, Vite. Стилизация через Tailwind CSS, анимации через Framer Motion.
- **Backend / Мультиплеер:** PartyKit WebSocket (авторитетный сервер).
- **Стейт-менеджмент:** Чистая функция `gameReducer` обновляет `GameState`. Действия (`GameAction`) валидируются сервером.
- **Безопасность (Anti-Cheat):** Состояние фильтруется сервером (`maskStateForPlayer`) перед отправкой клиенту для скрытия ролей оппонента.

## 2. Базовые правила и инварианты

- **Поле:** Сетка 5x5 (25 персонажей). В режиме 5 игроков — 6x6.
- **Соседство:** Клетки соседние, если `dr <= 1 && dc <= 1`. Максимум 8 соседей. Границы поля не замыкаются.
- **Смещение (Сдвиг):** Активный игрок может сдвинуть 1 ряд/колонку за ход. Вышедший за край персонаж возвращается с противоположной стороны.
- **Anti-Undo:** Запрет обратного сдвига линии, отменяющего ход соперника.
- **Зачистка:** Сдвиг мертвых персонажей в конец сетки.

## 3. Игровые режимы

1. **Схватка (SKHVATKA):** Бандит (цель: убить Инспектора или 14 подозреваемых) vs Инспектор (цель: задержать Бандита).
2. **Маньяк против оперативника (MANIAC_VS_OPERATIVE):** Охота по фиксированному списку из 4 жертв.
3. **Охота на грабителя (THIEF_HUNT):** Грабитель (цель: 10 сокровищ) vs Полиция (тайный шеф + 2 патрульных). Без зачистки поля.
4. **Секретная служба (SECRET_SERVICE):** Контрразведка. Сбор трофеев (разоблаченных агентов). Перекрестный опрос в радиусе 3x3.
5. **Очная ставка (LINE_UP):** Дедукция по внешним признакам карт без механик сдвига поля.

## 4. Требования к ТВ-режиму (Party Game)

- **Концепция:** Телевизор (общий экран 5x5) + Телефоны (персональные контроллеры).
- **Форматы:** Несколько телефонов (у каждого свой) ИЛИ один телефон (Pass and Play).
- **Отображение (ТВ):** Полное поле 5x5, таймеры, текущий ход, анимации перемещений, публичные события. Секретные данные скрыты.
- **Отображение (Телефон):** Видимость только 3-8 соседей, личная роль, кнопки действий, выбор линии для сдвига (абстрактные 5 полос). Вне хода — экран "Ожидание". В режиме одного телефона данные скрываются перед передачей устройства.
- **Интерфейс сдвигов (Телефон):** 1) Выбор оси (Горизонталь/Вертикаль). 2) Выбор линии (1-5). 3) Выбор направления. Подтверждение.
- **Завершение хода:** Выполняется явным нажатием кнопки "Завершить ход" после совершения доступных действий.

## 5. Инженерные стандарты и протокол работы

- **Изменения:** Выполняются исключительно через `patch.json` с точечными заменами (`patches`: `find`/`replace`).
- **Сборка и тесты:** Запуск `node patcher.cjs; npm test`. Отсутствие падений тестов (Zero Regression) — обязательное условие интеграции кода.
- **Поиск в патчах:** Поле `find` не должно содержать кириллицу, поиск опирается на латинские идентификаторы, классы Tailwind и логику.
- **UI Ограничения:** Action Bar находится в изолированном flex-слоте. Использование `fixed bottom-0` запрещено (Zero Board Shifting).
- **Палитра:** Строгий нуар (zinc, neutral, white, black, red, blue). Запрет на amber, yellow, cyan, emerald (кроме CR баланса и статуса ONLINE).
