# PROJECT_MASTER_TASKS: «Реквием: Последний выстрел» (The Wicked City)

## Описание проекта и архитектуры

Веб- и мобильная детективная настольная игра со скрытыми ролями для TV и смартфонов.
**Стек:** React 18, TypeScript, Vite, Tailwind CSS, Framer Motion, PartyKit (WebSocket).
**Архитектура мультиплеера (TV Mode):**

- Сервер `GameRoomServer` (PartyKit) управляет комнатой и маскирует состояние (`maskStateForPlayer`, `maskStateForTv`).
- Роутинг клиентов: `TV_DISPLAY` (общий экран 10-foot UI) и `CONTROLLER` (персональный геймпад).
- Стейт-менеджмент: чистая функция `gameReducer.ts`.

## Текущее техническое состояние

- **Тесты:** 233 из 233 тестов Vitest проходят успешно (Zero Regression подтвержден).
- **Сетевой слой:** Маршрутизация и стабильность сокетов PartyKit восстановлены. Ошибки `101 Switching Protocols` и `Network connection lost` устранены.
- **Интерфейс ТВ (TvBoardView):** Приведён к Мастер-ТЗ. Интегрированы оверлей сдвига, подсветка спец-ролей, экран завершения игры (GameOver) с показом победителя и раскрытием ролей.
- **Интерфейс Контроллера (MobileControllerView):** Двухэтапное подтверждение действий, модалка досье, стартовый выбор роли Инспектора, карты в руке, кнопки специфичных режимов (`CLEANUP`, `SWEAR_IN_OFFICER`), оверлей GameOver для реванша. Адаптивность вьюпорта переведена на `100dvh` с безопасными отступами `pb-8`. Ошибка `Rendered fewer hooks` полностью устранена.
- **Персистентность и сессии (TV-010, TV-034):** Реализовано кэширование `clientId` контроллера в `sessionStorage` против сброса при F5; очистка `clientType` в `partyService.disconnect()`.
- **Приватность и тактильность (TV-023, TV-035):** Внедрен Hold-to-Peek для защиты скрытой роли на телефоне; подключены звуковые эффекты (`soundManager`) и виброотклик (`triggerHaptic`).
- **Безопасность (P0 закрыто):** Сервер защищен от инъекций стейта, подмены ID и утечек закрытых данных.
- **Pass-and-Play (P0 закрыто):** Восстановлен режим игры с 1 телефоном. Добавлен выбор всех режимов в лобби ТВ.
